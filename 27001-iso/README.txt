  27001.iso
  An offline NIS2 / ZoKB starter pack. Yes, the name is a pun:
  ISO/IEC 27001 meets a disk image. It actually mounts.
═══════════════════════════════════════════════════════════════════

What this is
------------
A small, offline bundle for anyone whose organisation may fall under
the new Czech Cybersecurity Act — zákon č. 264/2025 Sb. (the NIS2
transposition), effective 1 November 2025. It is plain reference
material to help you start a conversation, not a product and not a
compliance service.

Everything here is public information, assembled in one place. There
is no tracking, no account, nothing to send back. It is the same Zero
Data Retention spirit as 0-click.com — an offline file you keep.

Contents
--------
  README.txt                  this file
  zakon-264-2025-summary.txt  one-page plain summary of the Act
  nis2-roles.html             offline reference: who does what
  nukib-contacts.vcf          public incident-reporting contacts
                              (NÚKIB / GovCERT.CZ) — import to contacts
  zokb-deadlines.ics          the two fixed dates — import to calendar

How to use it
-------------
  1. Read zakon-264-2025-summary.txt.
  2. Open nis2-roles.html in any browser (works fully offline).
  3. Import nukib-contacts.vcf so the incident-reporting numbers are
     in your phone BEFORE you ever need them.
  4. Import zokb-deadlines.ics so the dates are on your calendar.
  5. Run the self-identification calculator on the NÚKIB portal to
     find out whether — and in which regime — you are regulated.
